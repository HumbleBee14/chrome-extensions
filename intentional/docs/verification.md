# Verification

Run `npm run check` for lint, the core/tracker suite, and manifest entry-point validation. Run `npm run test:browser` for disposable-profile Chromium integration checks. Run `npm run test:reconnect` to reload the actual extension in a disposable Chromium profile and verify that the disconnected screen has working Reload and Leave actions. Disconnected Leave must open `about:blank` without contacting the worker; connected Leave opens Chrome’s New Tab page; the screen must not show daily-limit or midnight-reset copy. Run `npm run test:form` to check readable Add/Edit forms stay within desktop and mobile viewports, expanded options keep Save visible, info hints work on hover/focus/click, and name/note caps and colors persist. Run `npm run test:ui` for common-reason persistence, prefix hints, keyboard acceptance, Escape dismissal, and free text without automatic continuation, live message colors, live popup usage/countdowns and expiry without reopening, immediate dashboard agreement with stored usage after tab closure, popup editor links, section persistence, and 30-second warning dismissal across immediate refresh, child navigation, and the final seconds. These use disposable profiles with pregranted localhost/tabs access. The reconnect suite also relaunches the same disposable profile with an updated manifest version and verifies that existing common and legacy custom choices are retained. Results and screenshots are saved under `artifacts/`.

## Automated evidence

Core tests cover path boundaries, exact paths, subdomains, URL/network matching agreement, invalid input, overlapping allowances, bounded sleep gaps, midnight splits, required intentions/durations, shared session approval, duration caps, explicit renewal, override reason validation, shared override deadlines, independent attempt numbering, overlapping prevention, over-limit accounting, next-day resets, log retention, trusted management senders, and the default-off extension-page guard.

Tracker tests exercise the real accounting code with mocked Chrome window/tab/idle APIs. They verify focus pause/resume, reading without keyboard activity, screen locking, tab deduplication, runtime rehydration, no charging before approval, and immediate grant invalidation on path exit. These are not hardware tests.

The browser suite loads the actual source with a temporary manifest that pregrants localhost and tab permissions. It exercises forms, a real SPA fixture, keyboard interaction with the modal, local storage, declarative redirects, activity controls, exports, guard navigation, and narrow-screen layout. A small amount of state is seeded to reach deadlines quickly. Native optional-permission dialogs are not approved by this suite. Screenshots display a localhost fixture, not live YouTube or Reddit.

## Manual acceptance before release

1. Load the shipped `extension` folder in an ordinary Chrome profile. Deny and then allow a website permission request; check the form’s recovery state.
2. Add `youtube.com/shorts` as a prefix rule and `reddit.com/r/books` as a prefix rule. Navigate from each site’s home page into the monitored path without reloading. Verify prompts, child-path continuity, leaving/re-entry, and Escape containment.
3. Verify whole-domain limits, exact-path limits, subdomain inclusion/exclusion, trailing slashes, and overlapping rules. Confirm nearby path names are unaffected.
4. Continue through a prompt, watch a video, read without typing, switch tabs/apps, and lock/unlock the screen. Only the focused, unlocked tab should accrue daily time. Ensure gates pause normal page media.
5. Select a short session, leave the page, close/reopen the tab, and restart Chrome. The original deadline must remain in force and must not be extended by another prompt/tab.
6. Observe the live warning only during the final 30 seconds, dismiss it, and verify it stays hidden through the final seconds, refreshes, and child pages. Verify session expiry prefills the original reason in the editable field and permits explicit renewal within the remaining daily allowance. With less than a minute left, confirm Use remaining seconds works without retyping and records the accepted reason and precise duration. Verify daily expiry first shows Daily limit reached, Leave, and the reset reminder without reason/time fields. Choose extra time appears only when allowed and explicitly opens the form. Back and reload return to the limit screen; every expired override returns there too. Enable Prevent overrides and verify repeated network navigations are blocked. Check a local-midnight reset. Check sleep/wake behavior and a browser started after midnight.
7. Approve overrides repeatedly and verify numbered, highlighted entries and the separate time-over-limit summary. Review dates in the activity view, filter them, export, clear one day, and clear all logs. Daily counters, override attempt counts, over-limit totals, and active deadlines must stay intact. Delete a rule and erase all data; network redirects must be removed.
8. Enable and disable the extension-page guard, including while the extensions manager is already open. Revoke its tab permission. Confirm its explanation accurately states that toolbar removal and other bypasses remain available.
9. Revoke a monitored host’s access in Chrome, check the “Access needed” state, and restore access by saving the rule. Reload pages after upgrading the extension.
10. Check keyboard-only navigation, native dialog focus, zoom, reduced motion, light/dark site backgrounds, and narrow viewports. Inspect the extension error list for unexpected failures.

## Store submission

Publish the privacy policy at a public URL; supply accurate single-purpose, host-permission, tabs, webNavigation, and data-use disclosures. Include screenshots and listing assets. Do not advertise strict uninstall protection. Store approval and these manual checks are separate from local automated evidence.

Run `npm run test:activity` for seeded multi-day metrics, local-day selection, weekly drilldown, scoped export/clear, retained usage totals, Enter-to-save reason editing, and desktop/mobile layouts. `tests/activity.test.js` covers local week boundaries, unavailable legacy totals, overlapping-limit deduplication, midnight splitting, and aggregate pruning.

Run `npm run test:package` to build and load the actual release ZIP in a disposable Chromium profile with its unmodified manifest. This checks the bundled MIT license, optional host access, incognito exclusion, and Limits/Activity/Settings loading.
