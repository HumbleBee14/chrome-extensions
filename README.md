# Chrome Extensions

A collection of independently installable Chrome extensions.

| Extension | Description | Load unpacked from |
| --- | --- | --- |
| [VBlur](vblur/) | Blur YouTube videos and apply color overlays. | `vblur/` |
| [Intentional](intentional/) | Website and path limits, intentional visits, and activity insights. | `intentional/extension/` |

Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the relevant folder above.
