# Chrome Extensions

A collection of independently installable Chrome extensions.

| Extension | Description | Load unpacked from |
| --- | --- | --- |
| [VBlur](vblur/) | Blur YouTube videos and apply color overlays. | `vblur/` |
| [Intentional](intentional/) | Website and path limits, intentional visits, and activity insights. | `intentional/extension/` |

Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the relevant folder above.

Each extension has its own license:

- [VBlur license](vblur/LICENSE)
- [Intentional MIT license](intentional/LICENSE)

The original VBlur files and Git history are preserved. Its existing publishing workflow is retained under `vblur/.github/workflows/` and is inactive there. Shared publishing automation will be configured separately.

See [Intentional’s documentation](intentional/README.md) for development and testing instructions.
